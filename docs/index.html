    How it does

    2000 daily-style games. Two configs on the same risk dial.

    meanmax33s34s35s36s
    tail-averse (default)33.76355481382670

    The ~3% of 35-guess games are structural — see EXPERIMENTS.md for why search doesn't crack it.

    Use it on the real site

    1. Clone the repo; you only need extension/.
    2. Open chrome://extensions, turn on developer mode, Load unpacked, pick that folder.
    3. Open duotrigordle.com — the overlay shows the next guess.
